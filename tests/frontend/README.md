# Тесты фронтенда

Файлы из [examples/](../../examples/) используются одновременно как примеры и как входы golden-тестов.

Из корня проекта установите проект и зависимости для разработки:
```bash
python -m pip install -e ".[dev]"
```

Для запуска тестов фронтенда:
```bash
python -m pytest tests/frontend -q
```
